# 神經網路：要怎麼相信看似黑盒子的複雜模型？

## 課程大綱

神經網路 (Neural Network; NN)：源自生物學的發想，以及與資料科學的關聯

### 感知器 (Perceptrons)

神經網路的最基本結構！

**架構**：對只有單一輸出變數 $y$ 的模型， $\hat{y} = f\Big(\sum_i w_i x_i + b\Big)$

- **激勵函數** $f$：
  - Heaviside 階梯函數（單位階躍函數）
  - 邏輯斯諦函數（或 $\text{tanh}$）
  - 線性整流函式（ReLU）
  - Softplus

感知器好用嗎？事實上僅適用於 *線性可分* 的問題。

### 多層感知器 (Multi-layer Perceptrons; MLP)

最簡單且實用的神經網路。

**架構**：對只有單一輸出變數 $y$ 的模型， $h_j = f\Big(\sum_i^{m_1} w_{ji} x_i + b_j\Big),\quad \hat{y} = g\Big(\sum_j^{m_2} \tilde{w}_{kj} h_j + \tilde{b}_k\Big)$

- **隱藏層**：將線性感知器轉變為非線性模型的關鍵！
  - 模型具有許多參數。在神經網路的框架中，模型參數也稱為**權重**。
  - **超參數**：與架構相關的參數。例如：隱藏節點數量。

**損失函數**：最常見的選擇是均方誤差 (MSE)。

**求解器**：必須以數值方法求解。（見下文）

只要節點數量夠多，即使只有一層隱藏層，也能達到萬用近似（universal approximation）！

### 對非二次之損失函數進行最佳化 (aka 模型訓練)

非二次 (函數最高項次不是平方) 之損失函數 $J(\textbf{w})$ 在參數空間中可能有許多局部極小值，求得解析解幾乎是不可能的。不過我們還是可以利用數值方法求得單一個局部極小值，一個可行的策略為：

1. 找出損失函數最陡峭的下降方向；
2. 往那個方向前進，但是要前進多少長度則是個問題。

#### 牛頓法（Newton's method）

此方法須先計算赫氏矩陣 (Hessian Matrix) $\textbf{H}_0$，這個矩陣包含 $J$ 的所有二階導數在 $\textbf{w}_0$ 這個座標點的值。每一次的迭代求解會依照此式更新模型參數：

$\textbf{w}_{k+1} = \textbf{w}_k - \textbf{H}_k^{-1} \nabla J(\textbf{w}_k)$

#### 梯度下降法（Gradient Descent method）

此方法將赫氏矩陣 $\textbf{H}_0$ 替換為固定或彈性的步長 $\eta$，通常稱為**學習率**。每一次的迭代求解會依照此式更新模型參數：

$\textbf{w}_{k+1} = \textbf{w}_k - \eta \nabla J(\textbf{w}_k)$

### 對多層感知器進行最佳化

MLP 的結構使得 $\nabla J(\textbf{w})$ 難以計算，但好消息是我們有*反向傳播 (back-propagation)* 算法，只需要一個資料點，就能根據模型誤差 ($\hat{y} - y$) 推導出 $\nabla J(\textbf{w})$。「反向傳播」一詞的意思是先對輸出層的權重求梯度，再利用這些數值對前一隱藏層的權重求梯度，依此類推，整個流程會「傳播」到 MLP 的輸入層。

#### 反向傳播（Back-Propagation）

教科書中提到：「如今，『反向傳播』一詞的使用有些模稜兩可。」
- 它可能指原始的反向傳播演算法（搭配效率不佳的梯度下降法）
- 更可能是指僅使用其中涉及誤差反向傳遞的第一部分，來計算 $\nabla J(\textbf{w})$ 的方法。

由於反向傳播是以梯度下降法為基礎，因此需要預先設定**學習率**才能開始。

連接隱藏層與輸出層的權重：

$\Delta \tilde{w}_{kj}=-\eta\frac{\partial J}{\partial \tilde{w}_{kj}} = \eta(y_k-\hat{y}_k)g'(\tilde{s}_k)h_j$

連接輸入層與隱藏層的權重：

$\Delta w_{ji}=-\eta\frac{\partial J}{\partial w_{ji}} = \eta \sum_k (y_k-\hat{y}_k)g'(\tilde{s}_k) \tilde{w}_{kj}f'(s_j)x_i$

#### 使用反向傳播

由於只需要**一個資料點**就能計算 $\nabla J(\textbf{w})$，因此反向傳播演算法有兩種不同的應用方式：

- 序列訓練（Sequential training）：每次使用一個資料點更新權重
- 批次訓練（Batch training）：使用所有資料點更新權重（使用平均的 $\nabla J(\textbf{w})$）

**訓練週期（Epoch）**：所有資料點都被走訪（使用）過一次的時間。

反向傳播的程序可以重複執行任意多次，直到達到自訂的停止條件為止。例如：

- 當模型誤差（例如 RMSE）開始趨於穩定，甚至上升時
- 當驗證資料集的預測誤差開始趨於穩定，甚至上升時（**提前停止**）

### 極限學習機 (Extreme learning Machine; ELM)

這是針對上述挑戰所提出的一種解決方案。它使用集成方法的概念，將非線性問題轉換回線性問題。

**架構**：與 MLP 相同，另外再多兩條規則，使其轉換為線性問題：
  1. 輸入層的權重初始值是隨機指定的，而且不會迭代更新。
  2. 隱藏層的激勵函數是恆等函數；$f(x) = x$。

**損失函數**：與 MLP 相同。

**求解器**：對每個集成成員尋找解析解，所有的解再取平均。

### 調整超參數（模型驗證）

指定驗證資料的方式：
- 找一組獨立的驗證資料集，或從訓練資料中保留一部分供之後驗證使用。
- 交叉驗證（Cross-validation）：將資料分段並重複驗證，以利用所有訓練資料來驗證模型。
- 雙重交叉驗證（Double cross-validation）：一種進階的交叉驗證方法，用以避免輸入資料的序列相關所造成的問題。

在超參數空間中搜尋的方式：
- 網格搜尋（Grid search）
- 隨機搜尋（Random search）

### 集成技術（Ensemble technique）

集成技術有助於降低方差（variance error），同時不犧牲偏差（bias error）（第 8.3 節）。

- 裝袋法（Bagging）：自助抽樣（bootstrapping）；建立不同的（子）輸入資料集
- 堆疊法（Stacking）：結合完全不同的非線性模型。
